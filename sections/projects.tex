\section{Projects}
\projectHeading{Coconut Audio}{https://codeberg.org/Coconut-Audio}{C++, JUCE, CMake}
Free and open-source VST plugin development initiative. Plugins include Old Guitarist (physically modelled guitar), Intellectual Gate (drum bleed removal), Pulp Fiction (multi-FX rack) and Sound of Music (multiband bit crusher).\\
\sectionsep

\projectHeading{Mirdata}{https://mirdata.readthedocs.io/en/latest/}{Python}
Open-source Python library for loading and exploring music/audio research datasets. Contributions: dataset loaders for the Saraga Audiovisual and IAM Melodic Similarity datasets.\\
\sectionsep

\projectHeading{CompIAM}{https://mtg.github.io/compIAM/}{Python, PyTorch}
Repository of datasets, tools and models for computational analysis of Indian Art Music. Contributions: TCN Carnatic and BeatThis Carnatic beat-tracking modules.\\
\sectionsep

\projectHeading{Computational IAM Tutorial}{https://mtg.github.io/IAM-tutorial-ismir22/landing.html}{Python, Jupyter}
Contributed notebooks to the ISMIR 2022 tutorial on corpus-based research on Indian Art Music, covering the Saraga Audiovisual dataset and the TCN Carnatic module.\\
\sectionsep

\projectHeading{GeoSynth}{https://geosynth.vivekvjyn.xyz/}{Python, TensorFlow, Flask, Docker}
Sonification of geolocations using an autoencoder, with data collected through the Freesound API.\\
\sectionsep

\projectHeading{Markrethe}{https://markrethe.readthedocs.io/en/latest/}{Python}
Python package for logging experiments to a Markdown file.\\
\sectionsep

\projectHeading{TinkerHub CEC Website}{https://tinkerhub-cec-website.vercel.app/}{JavaScript, React}
Official website of TinkerHub CEC, the TinkerHub chapter at College of Engineering, Chengannur.
